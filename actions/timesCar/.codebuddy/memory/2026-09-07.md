# 2026-09-07

- 修复车型照片未关联的 bug（用户反馈「オーラ 的图没关联上」）。
  - **根因**：数据里实际车系名（`base`）带动力后缀，是 `オーラ e-POWER` / `ノート e-POWER`；而 `CAR_IMG_MAP` 的键写的是 `オーラ` / `ノート`，字符串精确匹配失败 → **这两张图其实一直都没显示**（ノート 同样中招，只是用户先发现 aura）。
  - **修法**：`build_web.py` 新增 `norm_key(s)` —— 小写化、去空格/连字符、去括号内容、去掉 `epower`/`ハイブリッド`/`hybrid` 后缀。`load_car_images(bases)` 接收数据中真实车系集合，用归一化键做匹配；同名多格式仍优先 png。
  - 构建输出新增诊断：`已关联车型照片 N/M 个车系`、缺图车系清单、未识别图片文件清单，便于下次排查。
  - 结果：9/9 车系全部关联成功。
- 顺带修复英文名副标题：`MODEL_EN` 只有不带后缀的键，`オーラ e-POWER` 会直接回退显示日文原名。新增 `modelEn(n)`：先精确查，再去掉括号后缀与 `e-POWER` 后重试，现在能正确显示 `AURA`。
- 经验：**日系车型的 `base` 名常带 `e-POWER`/`ハイブリッド` 等后缀**，任何按车系名做字典匹配的逻辑都必须先归一化，或在构建输出里打印「未匹配」清单，否则会静默丢图。
